# 💻 JGKenehen_Tech | Soluções em Hardware

Bem-vindo ao repositório oficial do **JGKenehen_Tech**, uma plataforma moderna estilo "Linktree" personalizada para centralizar meus serviços de manutenção de hardware, montagem de computadores e contatos profissionais.

Este projeto foi desenvolvido com foco em **Experiência do Usuário (UX)**, oferecendo uma interface rápida, responsiva e interativa para clientes que buscam soluções técnicas em Campo Mourão e região.

---

## 🚀 Funcionalidades Principais

- **Cards de Serviços Interativos:** Lista de serviços (Limpeza, Formatação, Montagem) com sistema de "accordion" (abre e fecha) e animações suaves de descida.
- **Redirecionamento Seguro:** Lógica implementada para evitar que links externos (como LinkedIn) quebrem ao serem abertos dentro do navegador interno do Instagram.
- **Interface Dark Mode:** Design moderno utilizando a paleta Slate e Cyan do Tailwind CSS para uma estética "Tech".
- **Totalmente Responsivo:** Otimizado para visualização em smartphones, tablets e desktops.

---

## 🛠️ Tecnologias Utilizadas

O sistema foi construído com o que há de mais moderno no ecossistema **React**:

- **React 18** + **Vite**: Para um ambiente de desenvolvimento ultrarrápido.
- **TypeScript**: Garantindo maior segurança e tipagem em todo o código.
- **Tailwind CSS**: Para estilização rápida e responsiva.
- **Lucide React**: Biblioteca de ícones minimalistas e modernos.
- **Vercel**: Hospedagem e deploy contínuo (CI/CD).

---

## 📂 Estrutura do Projeto

O código foi organizado seguindo as melhores práticas de modularização:

- `/src/components`: Componentes reutilizáveis como `ServiceCard` e `ActionLink`.
- `/src/data`: Separação de dados e textos do código lógico (ex: `services.tsx`).
- `/src/styles`: Configurações globais de CSS e Tailwind.
- `/public`: Ativos estáticos como a logo personalizada (SVG).
